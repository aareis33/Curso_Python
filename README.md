# Python 3 - Mundo 1 

## Sobre este repositório

Este projeto faz parte da minha jornada de transição de carreira para a área de tecnologia, unindo disciplina técnica com o objetivo de me tornar desenvolvedor de software. Cada exercício aqui representa um passo na construção de uma base sólida em lógica de programação.

## Licença

Este repositório tem fins exclusivamente educacionais.

## Sobre o curso

Curso introdutório de Python 3, com foco no desenvolvimento de lógica de programação. Aborda desde os primeiros comandos até estruturas condicionais, manipulação de texto e uso de módulos.
